# 학교 좌표 오류 보정과 이전 학교 분리

## 배경

외부에서 두 학교의 좌표가 틀렸다는 제보가 들어왔다.

- 대마초(전남 영광군 대마면): 고창군 대마교에 찍혀 있다.
- 인천이음초(인천 검단구): 856m 떨어진 김포시에 찍혀 있다.

## 확인 결과

### 인천이음초: 좌표 오류 (제보가 맞음)

- 기존 좌표(126.7142693, 37.6063529)는 김포시 풍무동 주택가였다.
- 2024년 업데이트 때 신설 학교 좌표를 `03_2023년도_학교기본정보.csv`에서 가져왔는데, 개교(2022-09) 직후였던 그때의 학교알리미 좌표가 틀려 있었다. 2026년 학교기본정보에서는 학교 위치(126.7126286, 37.5986598)로 바로잡혀 있다.

### 대마초: 좌표는 정확함

- 데이터 좌표는 학교알리미 공식 좌표, OSM에 그려진 학교 폴리곤, 위키데이터 좌표와 수십 m 안에서 일치한다. 위성영상에서도 학교 건물 위에 찍혀 있다.
- 다만 학교가 영광·고창 경계에 붙어 있어서, 공식 행정경계(admdongkor 2026-04-01, detail)로 판정하면 고창군 대산면 쪽으로 약 112m 넘어간 지점이다. 지도 서비스에 따라 고창군으로 보이는 이유로 추정한다. 데이터는 고치지 않았다.

### 전체 점검

전체 학교 좌표를 2026년 학교기본정보 좌표와 비교했더니 300m 넘게 차이 나는 학교가 46개였다. 각 좌표가 주소의 읍면동 안에 있는지 판정하고, 의심되는 학교는 위성영상(Esri World Imagery)과 웹 검색으로 확인했다.

| 학교 | 판정 | 근거 |
|---|---|---|
| 인천청호초 | 좌표 오류 | 기존 주소가 "인천광역시 서구"뿐이어서 지오코딩이 연희동 상가 건물을 찍었다. 2021년 청라에 개교한 뒤 이전한 적 없다. |
| 전주홍산초 | 좌표 오류 | 기존 주소가 "전라북도 전주시 완산구"뿐이어서 2km 떨어진 다른 학교를 찍었다. |
| 웅천초(여수) | 좌표 오류 | 기존 주소가 "전라남도 여수시"뿐이어서 여수시청을 찍었다. 웅천동은 시전동 관할 법정동이다. |
| 복사초(부천) | 이전 | 소사본동에서 계수·범박지구로 대체 이전(2024년 3월 개교 계획). 학생 수가 2023년 124명에서 2024년 222명으로 늘었다. |
| 홍주초(홍성) | 이전 | 2026년 3월 홍성읍에서 내포신도시(홍북읍 신경리 930-1)로 대체 이전. 학생 수 2025년 68명 → 2026년 239명. |

나머지 차이 중 중리초·삼산초·이동초·서남초·갈현초·대원초·금암초(28~95km 차이)는 학교알리미 좌표가 같은 이름의 다른 지역(이천 중리동, 순천 삼산동 등)을 가리키는 경우였다. 기존 좌표가 맞으므로 그대로 둔다.

## 변경 내용

`data/작업코드_2026.py`

- `COORD_FIX`: 좌표가 틀린 4개 학교(인천이음초, 인천청호초, 전주홍산초, 웅천초)의 좌표를 2026년 기본정보 좌표로 바꾼다. 주소가 시군구까지만 있던 3개 학교는 도로명 주소도 채운다.
- `RELOCATED`: 같은 학교 코드로 새 부지에 옮겨 간 학교(복사초 2024년, 홍주초 2026년)를 두 행으로 나눈다.
  - 이전 이력은 `data/16_학교이전이력.json`에 따로 기록하고, 스크립트는 이 파일을 읽는다. 항목마다 학교 코드, 새 자리에서 처음 집계된 연도, 옛·새 주소와 좌표, 메모, 근거 기사 URL을 둔다. 옛 주소가 기존 데이터와 다르면 스크립트가 멈춘다.
  - 옛 자리 행: id=NONE, 옛 주소·좌표, 이전 연도부터 학급·학생 수 0 (웹페이지에서 폐교로 표시)
  - 새 자리 행: 기존 학교 코드, 새 주소·좌표, 이전 연도 전까지 0 (신설처럼 표시)
  - 2025년에 새 코드로 다른 자리에 세운 대저중앙초·울산효문초를 옛 자리 폐교 행과 신설 행으로 둔 방식과 같다.
- 분류 결과(`14_분류결과_2025-2026.tsv`)에 "좌표 보정", "이전(새 자리)", "이전(옛 자리)" 유형을 추가했다.

재생성한 파일: `data/14_분류결과_2025-2026.tsv`, `data/15_최종정리_2008-2026.tsv`, `docs/schoolInfo_2026.tsv` (7,081행 → 7,083행)

`src/index.js`: 행 수가 늘어서 `filteredCount`(슬라이더를 움직이기 전 하단에 표시되는 학교 수)를 7081 → 7083으로 바꾸고 `npm run build`로 `docs/main.js`를 다시 만들었다.

## 테스트 결과

- 스크립트의 검증(행 수, 빈 값, 좌표 범위, 2025·2026년 학생 수 합계)을 모두 통과했다.
- 다시 비교한 결과, 수정한 6개 학교는 모두 2026년 공식 좌표와 일치한다.
- 보정한 좌표는 모두 위성영상에서 학교 건물·운동장 위에 있다.

## 남은 이슈·참고

- 검색 자동완성의 라벨이 "이름/시도 시군구"라서, 이전 학교(복사초·홍주초)와 대저중앙초는 같은 라벨이 두 번 나온다. 검색으로 선택하면 뒤에 있는 새 자리 행으로 이동한다.
- 공식 좌표와 300m 넘게 차이 나는 학교가 아직 40개 있다. 큰 차이(수 km 이상)는 대부분 학교알리미 좌표가 틀린 경우로 확인했으나, 같은 읍면동 안에서 수백 m~수 km 차이 나는 학교(지례초, 의항분교장, 오음초, 신동초, 하서초 등)는 아직 개별 확인하지 않았다.
