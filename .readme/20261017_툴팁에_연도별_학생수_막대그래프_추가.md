# 툴팁에 연도별 학생 수 막대 그래프 추가

작업일: 2026-10-17 · 브랜치: `basemap-positron`

## 배경
- 학교 위에 마우스를 올리거나 클릭하면 나오는 정보 상자에는 2008년과 마지막 해의 학생 수만 있었다. 그 사이의 변화를 바로 볼 수 있도록 연도별 막대 그래프를 넣었다.

## 변경 내용 (`src/index.js`)
- 데이터 가공: 학교마다 연도별 학생 수 배열 `students`를 만든다. 선 그래프 폴리곤을 만들 때 쓰는 값과 같다.
- `showInfoBox`
  - 상자 높이를 155px(글자) + 150px(그래프)로 늘렸다. 글자 위치와 크기는 그대로다.
  - 기본 위치는 예전처럼 마우스 위쪽이다. 위쪽 공간이 모자라면 마우스 아래쪽으로 뒤집고, 좌우는 화면 안에 들어오게 맞춘다. 폭은 `min(400, 화면 폭 - 16)`이다.
- `drawStudentBars` (새 함수)
  - 2008~마지막 해까지 `yearCount`개의 막대. 윗변 모서리만 둥글게(4px) 그린다 (`roundedTopBar`).
  - 세로 축척은 학교마다 자기 최댓값에 맞춘다. 학생 수가 적은 학교도 변화 모양이 보인다.
  - 수치는 반시계 90도 돌려서 막대 바로 위에 흰 글씨(11px)로 쓴다. 0인 해도 0을 쓴다.
  - 막대 아래에 연도를 두 자리(`08`…`26`)로 쓴다.
  - 막대 색은 지도의 학교 색과 같다(증가 빨강, 감소 노랑). 폐교·휴교는 지도의 회색이 검은 바탕에서 잘 보이지 않아 더 밝은 회색(`rgb(150,150,150)`)을 쓴다.

## 테스트
- 로컬(`python -m http.server`, Chrome): 서울둔촌초에서 2008~2017년 감소, 2018~2024년 휴교(0), 2025~2026년 재개교 모양이 그대로 보임. 화면 위쪽 끝의 서울신명초에서 상자가 마우스 아래로 뒤집히고 오른쪽 끝에서 화면 안으로 들어옴. 콘솔 오류 없음.

## 남은 이슈 / 참고
- 화면 폭이 좁은 모바일에서는 상자 폭이 줄어 막대와 수치가 촘촘해진다. 실제 휴대폰에서는 확인하지 않았다.
