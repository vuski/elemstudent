# 2025·2026년 데이터 업데이트

작업일: 2026-10-17 · 브랜치: `data-2026`

## 배경
- 사이트(`student.sisain.co.kr`)는 2008-2024년 자료였다. 학교알리미의 2025·2026년 "학교 현황(초)"과 2026년 "학교기본정보(초)"를 받아 2008-2026년으로 갱신했다.
- 원천 파일 위치: `A:\work\202305_초등학교학생수\20261017_추가데이터`
- 2024년 업데이트 때 쓴 스크립트는 남아 있지 않았다. 그래서 `A:\work\202305_초등학교학생수\최종정리`의 `08` → `09_2024일단조인버젼` → `schoolInfo_2024.tsv`를 비교해 당시 처리 규칙을 복원하고, 그 규칙을 따랐다.

### 처리 규칙
- 학교 코드로 2025·2026년 학급수·학생수를 붙인다. `"30(1)"`은 괄호 앞 숫자만 쓴다.
- 해당 연도 현황에 없거나 자료가 없는 학교(2025년 단밀초)는 0으로 둔다.
- 기존 학교의 이름·주소·좌표·시도·시군구는 바꾸지 않는다.
- **재개교 2곳**(서울둔촌초, 서울위례초): 재건축으로 2018년부터 쉬었다가 같은 자리에서 다시 열었다(설립일 동일, 위치 10m 이내). 기존 폐교 행(`id=NONE`)에 새 코드를 붙여 기록을 이었다.
- 대저중앙초, 울산효문초는 옛 학교와 이름만 같고 2025년에 다른 자리(5.5km, 1.2km)에 세운 학교라서 신설로 처리했다.
- 통합으로 새로 생긴 학교(예: 김천 지품천초)는 신설로, 통합 전 학교는 폐교로 둔다.
- 신설 학교의 시도·시군구는 기존 표기로 맞췄다: `전남광주통합특별시` → 광주 5개 구는 `광주`, 나머지는 `전남` / 인천 `영종구` → `중구`, `검단구` → `서구` / `화성시 동탄구` 등 → `화성시`. 스크립트는 기존에 없는 시도·시군구가 나오면 멈춘다.
- 지역 칸이 빈 인천신검단초는 도로명 주소에서 지역을 읽었다.

### 결과
- 7,015개교 + 신설 66개교 = **7,081개교**
- 2025년 폐교·휴교 36개교, 2026년 폐교·휴교 55개교, 재개교 2개교
- 2026년 최대 학생 수 2,168명

### 웹페이지
- `src/index.js`: `schoolInfo_2026.tsv`, `countMax = 2168`, `yearCount = 19`, `filteredCount = 7081`, `lastYear = "2026"`, `COL_OFFSET = 26`, `class_2026`·`student_2026` 참조.
- `src/index.js`: 마지막 해 학생 수 라벨 위치를 `d.polygon[16]` → `d.polygon[yearCount]`로 고쳤다. 2024년 업데이트 때 바꾸지 않아 2024년 숫자가 2023년 점 위치에 찍히던 문제다.
- `src/index.html`: "2024" 연도 문구 6곳(og:title, twitter:title, title, 안내 모달 3곳)을 "2026"으로 바꿨다. 다른 메타태그와 Google 태그는 그대로다.
- `npm ci` 후 `npm run build`로 `docs/index.html`, `docs/main.js`를 다시 빌드했다. `docs/CNAME`은 그대로다.

## 테스트
- 스크립트 내부 검증 통과: 학교코드 중복 없음, 빈 값 없음, 좌표가 한국 범위 안, 2025·2026년 현황의 모든 학교가 결과에 있음, 연도별 학생 수 합계가 원본과 일치.
- 좌표가 없던 9개교: 네이버 결과를 OpenStreetMap 학교 위치와 대조해 5곳이 50m 이내로 일치함을 확인.
- 로컬 확인(`python -m http.server`, Chrome): 제목 "2008-2026년", 하단 "7081개소", 슬라이더 최대 2,168명, 콘솔 오류 없음. 인천신검단초(0→1,651명) 선 그래프와 정보 상자, 서울둔촌초·서울위례초의 휴교 후 재개교 모양 확인.

## 남은 이슈 / 참고
- `docs/titleImage.jpg`, `titleImage2.jpg`(SNS 공유 이미지)에는 연도 문구가 없다. 다만 예전 자료로 찍은 지도 화면이라 수치가 지금과 다르다. 그대로 두었다.
- 기존 학교의 시도·시군구는 2026년 행정구역 개편(전남광주통합특별시, 인천 영종구·검단구 등)을 반영하지 않았다. 경계 geojson도 예전 그대로다.
- 네이버 지오코딩 API 키는 이 저장소에 저장하지 않았다. 결과 좌표만 13번 파일에 남겼다.
